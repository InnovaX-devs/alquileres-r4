Setup inicial 
 
1. Hacer pull del repositorio
git pull

 
2. Crear el archivo de configuración (desde la carpeta backend/)

cd backend

cp src/main/resources/application.properties.example src/main/resources/application.properties

Ese comando copia el contenido de `application.properties.example` en `application.properties`.
 
3. Completar los datos de conexión
Abrí `src/main/resources/application.properties` y:
- Completá la URL, usuario y contraseña de la base (pedíselos al equipo, no se guardan en el repo)
- Completá el email y la contraseña de aplicación de Gmail
> ⚠️ El archivo `application.properties` está en `.gitignore` y nunca debe subirse al repositorio.
 
4. Instalar dependencias (desde backend/)
mvn clean install

 
5. Correr la app
mvn spring-boot:run

 
La app levanta en `http://localhost:8080`
